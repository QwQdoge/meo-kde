# Google Material icon resources

The `material-icons-round/` directory contains the small, selected subset of
Google Material Icons Round SVGs used to provide KDE icon-theme fallbacks.
The Shell itself uses the bundled current Material Symbols Rounded variable
font, giving selected controls MD3 fill and weight behaviour.

Source: https://github.com/google/material-design-icons
