# UX test record

Record environment, resolution, scaling, input method, elapsed time, mistakes,
and result for each run.

1. Meta, type an application name, press Enter, and verify launch and focus.
2. Connect to Wi-Fi from the system tray and verify connecting/error states.
3. Change volume and brightness and verify the displayed system value.
4. Open System Settings from the status area.
5. Open the power menu and distinguish lock, log out, restart, and shut down.
6. Switch multiple applications with Alt+Tab and the shelf.
7. Complete launcher search using only the keyboard.

Capture normal, hover, active, keyboard-focus, disabled, light, dark,
1366x768, and high-DPI evidence for changed custom components.
