# KDE icon usage audit

The installed Plasma 6 settings modules currently reference semantic names such
as `preferences-system-network`, `preferences-desktop-keyboard`,
`network-wireless-symbolic`, and `system-log-out`. MeoSymbols maps the core
settings, status, device, place and action names; detailed or vendor-specific
modules fall back to Breeze then hicolor.
